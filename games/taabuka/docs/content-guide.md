# ター深 コンテンツの書き方

> このファイルは `node tools/check.mjs --docs` が語彙の登録内容から自動で書き出す。手で直さない。

札・常連客・置物・お品書き・敵・層・謎・宿泊客は全てYAMLで書き、効果は「合図（when）・条件（if）・効果（do）」と
「ルール改変（rule）」「演出（show）」の決まった語彙だけで書く。語彙で書けないものだけ特注（*.js）を書き、名前を付けて語彙に加える。

書いたら `node tools/check.mjs` を実行する。おかしなところが1件1行で出る（知らない語彙には近い候補も出る）。
ファイルを足したら `node tools/check.mjs --fix-index` で content/index.yaml を書き直す。

## ファイルの置き場所

| 何を | どこに |
|---|---|
| セット | `content/sets/<セットID>/set.yaml` |
| 札・常連客・置物・お品書き | 同じフォルダの `cards.yaml` `regulars.yaml` `relics.yaml` `items.yaml` |
| キーワード能力 | 共通は `content/keywords/*.yaml`、セット固有は同じフォルダの `keywords.yaml` |
| 語彙で書けないものの特注 | 同じフォルダの `custom/*.js` |
| 宿泊客 | `content/guests/<ID>/guest.yaml` と固有の仕組みの `custom.js`（専用札は sets/ に置く） |
| 敵 | `content/enemies/<層>.yaml`（特注は `content/enemies/custom/*.js`） |
| 層 | `content/layers/<層>.yaml` |
| 謎 | `content/events/<層>.yaml`（ファイル名の layerN が出る層） |
| お土産 | `content/souvenirs.yaml` |
| 宿の施設と段階 | `content/facilities.yaml` |
| 札同士のコンボ・呪文の短い名前 | `content/combos.yaml` |

書き方の雛形は `docs/templates/` にある。差し込み口の一覧は `docs/hooks.md`。

## 決まった値

- カテゴリ（13）：食べ物・死・宿・動物・スレ・湯・校庭・速さ・格ゲー・ター・老・麺・ロボ。札1枚に1〜3個
- Tier：God / 0 / 1 / 2 / 3 / 4 / 5 / 8（輪：God→0→1→2→3→4→5→8→God）
- 番付の段：God / 0 / 1 / 2 / 3 / 4 / 5 / 8 / 欠6 / 欠7
- 格：並 / 上 / 特上 / 極 / 神
- 組（優先順）：重なり
- 由来（origin）：orig（原本・省略時） / expiry（期限） / cursed（曰く付き） / bet（賭け）。copy と pawn は宿が付ける
- ID：英小文字・数字・_。セットの頭文字＋名前（例：rk_shineei）。一度決めたら変えない

## 札（cards.yaml）

```yaml
- id: rk_shineei            # セットの頭文字＋名前
  name: 死ねーぃ
  cat: [死]                  # 1〜3個
  tier: 1                    # God / 0 / 1 / 2 / 3 / 4 / 5 / 8
  grade: 特上                # 並 / 上 / 特上 / 極 / 神
  kw: [一番槍]               # キーワード能力（省略可）。数字を取るものは 呼び水2 のように
  text: 狙った敵の主張を0にする（層主・底の主は半分）。その戦闘の残りは出し−1
  flavor: 一言で終わる。      # 笑いの一行。効果文とは別
  fx:                        # 効果。when・if・do を並べる
    - when: 採点時
      if: { 確率: 0.5 }      # 省略可
      do:
        - 主張を削る: { 対象: 狙い, 割合: 1.0, 層主なら: 0.5 }
        - 出し回数: { 増減: -1, 期間: 戦闘 }
  rule: [効果文を偽る]        # 持っている間ずっと効くルール（省略可）
  show:                      # 演出（省略可）
    - 筆文字: 死ねーぃ
    - 斬る
  test:                      # 自己テスト（省略可。検査コマンドが実行する）
    - hand: [rk_shineei, { tier: 3, cat: [麺] }]
      play: [0]
      enemies: [{ claim: 1000 }]
      expect: { enemy0: 0 }
```

常連客（regulars.yaml）は cat・tier の代わりに grow（成長型）を持てる：`grow: { 増える: 下りた階, 量: 0.05, 永続: true }`（増える：下りた階／出し／戦闘／脱出）。
置物（relics.yaml）は札と同じく fx・rule・show を持つ。お品書き（items.yaml）は `kind: 議題|番付札|品`、`use: 戦闘中|いつでも|戦闘外`、`do:`（議題は `hand:` に組）。

### 「この札」は誰か

- 札の効果：その札自身。
- 常連客・置物・宿泊客の効果で合図が「採点時」「手札に残る」：そのとき採点された（残った）札。

## キーワード能力（16）

札に「短い名前（＋数字）」で付ける能力。札の側は `kw: [二倍, 呼び水2]` と名前を並べるだけで、読み込み時に中身（fx・rule・show）が札に展開される。
中身は `content/keywords/*.yaml`（共通）か `content/sets/<セット>/keywords.yaml`（セット固有）に一度だけ書く（雛形 docs/templates/keyword.yaml）。
数字を取るものは定義に `arg: N` を書き、中身の N が札の数字になる。語彙で書けないものは `custom:` で特注（custom/*.js の rule）を指す。
セット固有のキーワードは、そのセットが解放された後なら他のセットの札からも使える。常連客・置物にも付けられ、敵に付けたものは表示だけ。
札の説明文には、キーワード名が太字で自動で先頭に並ぶ（text にはキーワード以外の効果だけ書く）。
定義には `test:` で自己テストを書く。手札は `{ tier: 3, kw: [呼び水2] }` のようにその場の札で書ける（`draw:` は山札、`deck:` は戦闘の前のデッキ）。

| 名前 | 効果 | どこの | 中身 |
|---|---|---|---|
| `二倍` | この札を含む出しは、採点も常連客の発動も全部2回ずつ起きる | セット ryukogo | 特注 nibai |
| `交互` | 出した札を全て採点し、カテゴリが交互になるよう並べ替え、交互が続いた数だけ倍率×1.5 | セット ryukogo | 特注 kougo |
| `宣言` | 出すときにカテゴリを1つ宣言し、出した札が全てそのカテゴリを持っていることにする | セット ryukogo | 特注 sengen |
| `伏せ字` | 何が起きるかは出すまで分からない（解放済みの目玉ルールから1つ） | セット ryukogo |  |
| `消える` | 出すと捨て札に行かず、その戦闘から除かれる | 共通 |  |
| `初手` | 戦闘開始時に必ず手札に入る | 共通 |  |
| `呼び水N` | 採点されると札をN枚引く | 共通 |  |
| `余韻N` | 採点されると、次の出しの最初に強さ＋N | 共通 |  |
| `守りN` | 受けに回ると受け＋N | 共通 |  |
| `連れN` | 同じ出しに同じカテゴリの札が他にあれば倍率＋N | 共通 |  |
| `一番槍` | その戦闘の最初の出しなら倍率×2 | 共通 |  |
| `とどめ` | この札を含む出しで敵を倒すと宿銭＋2 | 共通 |  |
| `重ね数N` | 揃いの判定でN枚分として数える（組は5枚分まで） | 共通 |  |
| `根回し` | 採点されると、この札のカテゴリを番付で1段上げる | 共通 |  |
| `祟りN` | 手札にある間、ターン終了時に体力−N | 共通 |  |
| `不壊` | 硝子でも割れず、消える効果を受けない | 共通 |  |

## 語彙：合図（when、19）

| 名前 | 意味 |
|---|---|
| `採点時` | この札が採点されたとき（常連客・置物・宿泊客は、採点札1枚ごと） |
| `手札に残る` | 出しのとき、この札が手札に残っていたら（手札の左から1枚ずつ） |
| `受けに回る` | この札が出されて採点されず、受けになったとき |
| `出し` | 出しの計算で、常連客は左の席から、置物は手に入れた順に |
| `出しの前` | この札を出す直前（組の判定より前） |
| `出しの後` | この札を出し終えた後（与えて、受けを足した後） |
| `流した時` | この札を流したとき |
| `引いた時` | この札を引いたとき |
| `ターン開始` | ターンの始め（引いた後）。札は手札にあるときだけ |
| `ターン終了` | ターンの終わり（敵の番の前）。札は手札にあるときだけ |
| `戦闘開始` | 戦闘の始め |
| `戦闘終了` | 戦闘の終わり（勝ちでも負けでも） |
| `敵を倒した時` | 敵を1体倒すたび |
| `過剰論破の時` | 過剰論破（論破以上）が出たとき |
| `敵の行動の前` | 敵が1体行動する直前 |
| `階に入った時` | 階に入ったとき（置物・常連客の fx に届く） |
| `部屋に入った時` | 部屋に入ったとき（置物・常連客の fx に届く） |
| `踊り場` | 踊り場に着いたとき（置物・常連客の fx に届く） |
| `脱出時` | 脱出したとき（置物・常連客の fx に届く） |

## 語彙：条件（if、35）

1つのオブジェクトに複数書けば全て成り立つとき。並べても全て成り立つとき。`{ 採点札のカテゴリ: 食べ物, 枚数以上: 3 }` のように補う項目を持つものがある。

| 名前 | 引数 | 意味 |
|---|---|---|
| `場の状態` | ノリノリ ／ しんみり ／ グダグダ ／ お祭り ／ 修羅場 ／ 演歌 ／ 静寂 ／ 大団円 ／ 何か | いまの場の状態がこれ（「何か」ならどれでも） |
| `値` | { 式: 数か式, 以上: 数（省略可）, 以下: 数（省略可） } | 式の値が 以上／以下（宿泊客の状態や札の熟成などを比べる） |
| `重なり以上` | 整数 | 採点札で同じカテゴリが N 枚以上重なっている（カテゴリを書けばそのカテゴリ。「この札」も書ける） |
| `カテゴリの種類以上` | 整数 | 採点札のカテゴリが N 種類以上（2枚以上重なったものだけ数えるなら 重なったものだけ: true） |
| `効果なし` | true／false | この札が効果の無い札（バニラ） |
| `効果なしの札` | 整数 | 採点札のうち効果の無い札が N 枚以上 |
| `レアリティ以上` | 文字 | この札のレアリティがこれ以上 |
| `カテゴリ` | カテゴリ | この札がこのカテゴリを持つ |
| `採点札のカテゴリ` | カテゴリ | 採点札のうちこのカテゴリの札が「枚数以上」枚（省略時1） |
| `同じカテゴリの札が他に` | true／false | 同じ出しに、この札とカテゴリを共有する札が他にある |
| `Tier` | Tier | この札のTierがこれ |
| `Tier以上` | Tier | この札のTierがこれ以上（Godが一番上） |
| `番付` | { カテゴリ: カテゴリ, 以上: 番付の段（省略可）, 以下: 番付の段（省略可）, 段: 番付の段（省略可） } | カテゴリの番付の段が 以上／以下／ちょうど |
| `採点枚数` | 整数 | 採点札がちょうどN枚 |
| `手札枚数以下` | 整数 | 手札がN枚以下 |
| `山札枚数以下` | 整数 | 山札がN枚以下 |
| `このターンの出し` | 整数 | このターンN回目の出し |
| `戦闘の出し` | 整数 | この戦闘N回目の出し |
| `戦闘のターン以上` | 整数 | 戦闘のNターン目以降 |
| `体力の割合以下` | 数 | 体力が最大のこの割合以下 |
| `階以上` | 整数 | B(N)以降 |
| `宿銭以上` | 整数 | 潜行で持っている宿銭が N 以上 |
| `気配以上` | 整数 | 気配がN以上 |
| `深度以上` | 整数 | 深度がN以上 |
| `敵の種類` | 通常 ／ 精鋭 ／ 層主 ／ 追跡者 ／ 番人 ／ 底の主 | 狙った敵の種類（通常／精鋭／層主／追跡者／番人／底の主） |
| `敵の数` | 整数 | 残っている敵がちょうどN体 |
| `手札の位置` | 端 ／ 左端 ／ 右端 | この札が手札の 端／左端／右端（出した札は出す前の位置） |
| `採点の順番` | 最初 ／ 最後 | この札が採点札の 最初／最後 |
| `由来` | orig ／ copy ／ expiry ／ cursed ／ pawn ／ bet | この札の由来（orig／copy／expiry／cursed／pawn／bet） |
| `確率` | 数 | この確率で（0〜1） |
| `どれか` | 条件の並び | 並べた条件のどれかが成り立つ |
| `すべて` | 条件の並び | 並べた条件が全て成り立つ |

## 語彙：効果（do、41）

`do:` には `- 名前: 引数` を並べる。数のところには式も書ける（下の「式」）。
「強さ」「倍率」「掛け」「論破値を掛ける」は合図「採点時」「手札に残る」「出し」でだけ使える。

| 名前 | 引数 | 意味 |
|---|---|---|
| `強さ` | 数か式 | 強さ（S）に足す |
| `倍率` | 数か式 | 倍率（M）に足す |
| `掛け` | 数か式 | 倍率（M）に掛ける |
| `論破値を掛ける` | 数か式 | 最後の S×M にさらに掛ける |
| `受け` | 数か式 | 受けに足す |
| `体力` | 数か式 | 体力を増やす（負なら減らす）。最大を超えない |
| `引く` | 数か式 | 札をN枚引く |
| `捨てる` | { 対象: この札 ／ 手札全部 ／ 手札の乱数 ／ 手札の一番強い ／ 手札の一番弱い ／ 手札の左端 ／ 手札の右端 ／ 出した札 ／ 手札から選ぶ（省略可）, 枚数: 整数（省略可） } | 手札の札を捨て札へ |
| `出し回数` | { 増減: 数か式, 期間: ターン ／ 戦闘（省略可） } | 出しの回数を増減 |
| `流し回数` | { 増減: 数か式, 期間: ターン ／ 戦闘（省略可） } | 流しの回数を増減 |
| `手札上限` | { 増減: 数か式, 期間: ターン ／ 戦闘（省略可） } | 手札の上限を増減 |
| `番付を上げる` | { カテゴリ: カテゴリ, 段: 整数（省略可） } | カテゴリの番付を段数だけ上げる |
| `番付を下げる` | { カテゴリ: カテゴリ, 段: 整数（省略可） } | カテゴリの番付を段数だけ下げる |
| `番付を入れ替える` | { カテゴリ: カテゴリ, 相手: カテゴリ } | 2つのカテゴリの段を入れ替える |
| `番付を移す` | { カテゴリ: カテゴリ, 先: 番付の段 } | カテゴリを指定の段へ（欠番を含む） |
| `番付を反転` | （引数なし） | 番付を上下反転（God⇔8、0⇔5…。欠番はそのまま） |
| `番付を均す` | 番付の段 か （引数なし） | 全カテゴリを同じ段へ（省略時は潜行開始の段） |
| `番付を階の始めに戻す` | （引数なし） | 番付を、その階に入った時の形に戻す |
| `札を変える` | { 対象: この札 ／ 手札全部 ／ 手札の乱数 ／ 手札の一番強い ／ 手札の一番弱い ／ 手札の左端 ／ 手札の右端 ／ 出した札 ／ 手札から選ぶ（省略可）, Tier: Tier か 文字（省略可）, カテゴリを足す: カテゴリ（省略可）, カテゴリを変える: カテゴリ（省略可）, 強さ: 数か式（省略可）, 期間: 戦闘 ／ 潜行（省略可） } | 札のTier・カテゴリ・強さを変える |
| `札を生む` | { id: 札のID, 場所: 手札 ／ 山札の上 ／ 山札の下 ／ 捨て札（省略可）, 写し: true／false（省略可）, 期間: 戦闘 ／ 潜行（省略可）, 枚数: 整数（省略可） } | 札を作って置く（写しなら版と判を持たない） |
| `札を消す` | この札 か 手札全部 か 手札の乱数 か 手札の一番強い か 手札の一番弱い か 手札の左端 か 手札の右端 か 出した札 か 手札から選ぶ か { … } | 札を消す（戦闘：この戦闘だけ除く／永続：デッキから消える） |
| `山札の上に置く` | （引数なし） | この札を山札の一番上に置く（次に引く） |
| `次の出しの強さ` | 数か式 | 次の出しの最初に強さ（S）に足す |
| `主張を削る` | { 対象: 狙い ／ 敵全員 ／ 乱数 ／ 左端 ／ 一番強い（省略可）, 割合: 数（省略可）, 量: 数か式（省略可）, 層主なら: 数（省略可） } | 敵の主張を割合か量で削る（層主・底の主は「層主なら」の割合） |
| `行動停止` | { 対象: 狙い ／ 敵全員 ／ 乱数 ／ 左端 ／ 一番強い（省略可）, ターン: 整数 } | 敵がNターン行動できない |
| `行動を消す` | 狙い ／ 敵全員 ／ 乱数 ／ 左端 ／ 一番強い | 敵の次の行動を無効 |
| `場の状態` | ノリノリ ／ しんみり ／ グダグダ ／ お祭り ／ 修羅場 ／ 演歌 ／ 静寂 ／ 大団円 | 場の状態を変える（ノリノリ・しんみり・グダグダ・お祭り・修羅場・演歌・静寂・大団円。前の状態は上書き。続くターンと効果は数値表 moods） |
| `宿銭` | 数か式 | 宿銭を得る |
| `お品書きを得る` | お品書きの種類（議題／番付札／品） | お品書きを得る（空きがあれば） |
| `お土産を得る` | お土産のID | お土産を得る |
| `気配` | 整数 | 気配を増減 |
| `脱出` | true／false | その場で脱出する |
| `育つ` | 数か式 | この札・常連客の育ちを増やす |

## 特注（custom/*.js）

```js
export default {
  name: '二倍',                       // 語彙として呼ぶ名前
  kind: 'rule',                       // rule / do / show / mechanic / enemy / if / var
  text: 'この出しの処理を全部2回通す', // 説明1行（この手引きに出る）
  args: { '回数?': 'int' },           // 受け取る値の形（省略可）
  hooks: {                            // 差し込み口：(ctx, next, me)。me.params に YAML で渡した値
    'score.card': (ctx, next, me) => { next(); next(); },
  },
  on: { 採点時: (ctx, me) => {} },     // 合図：(ctx, me)
  tests: [                            // 自己テスト（下）
    { hand: ['rk_jujo_satosatoru'], expect: { V: 35 } },
  ],
};
```

- kind が rule のものは apply(B, env, r) と expire(B, env, r) で掛けた瞬間・外れる瞬間の処理も書ける。
- kind が do のものは run(E, 引数)、if は test(E, 引数)、var は get(E) を書く。
- kind が mechanic（宿泊客の仕組み）は state（戦闘をまたいで残る値の初期値）・vars（式で使える名前）・
  actions（固有行動）・status(B, me)（画面に出す1行）を持てる。
- kind が enemy（敵の特注）は hooks・on と、acts（その敵だけの行動の語彙）を持てる。
- 特注が例外を投げたら、その効果だけを無かったことにして続け、戦闘の記録に残る。

## 自己テストの書き方

```yaml
test:
  - hand: [rk_shineei, { tier: 3, cat: [麺], name: 長い名前, kw: [呼び水2] }]   # IDか、その場で作る札
    draw: [{ tier: 1 }]  deck: [{ tier: 1 }]   # 山札（手札を書いたとき）／戦闘前のデッキ（手札を書かないとき）
    play: [0]                       # 出す札（省略時は全部）
    enemies: [{ claim: 1000, kind: 層主 }]   # 省略時は主張 1e30 の的が1体
    seats: [常連客ID]  relics: [置物ID]  guest: 宿泊客ID  banzuke: { 麺: God }
    state: { 採配数: 3 }             # 宿泊客の値
    choices: { 宣言: 神組 }          # プレイヤーが選ぶもの
    steps: [{ play: [0] }, { discard: [0] }, { end: true }, { guest: 採配, args: {…} }, { item: 0 }]   # 順に（省略可）
    expect: { … }
```

expect に書けるもの：V、V以上、V以下、組、enemy0（敵の主張。番号は左から）、受け、体力、宿銭、出し残り、結果（win／lose／escape）、番付、段位、状態（宿泊客の値）、行動停止、記録（記録の種類）、エラー（記録された例外の数）、演出、なしより大きい、なしの倍、手札枚数、山札枚数、捨て札枚数、除外枚数（その戦闘から除かれた札）、手札に（札の名前）。
「なしより大きい」「なしの倍」は、その札の効果（特注のテストではその特注）を外して同じことをした結果と比べる。

## 検査コマンド

`node tools/check.mjs [セットID…]`

1. YAMLと形の検査（必須項目、値の範囲、知らない語彙）
2. IDの重複と参照先の存在
3. content/index.yaml の確認（`--fix-index` で書き直す）
4. 自己テストの実行
5. 札ごとの試し対戦（`--trial`。その札を2枚入れた初期デッキで潜らせ、同じ格の平均と比べて「強すぎ／弱すぎ／普通」。時間がかかる）

キーワード能力は、未定義の名前（近い候補つき）、名前の重複、数字の過不足、解放順で先に来るセットの札が後で解放されるセットのキーワードを使っていることを指摘する。

ほかに `--docs`（この手引きと hooks.md を書き出す）、`--ids`（docs/ids.md に既存IDの一覧）。
