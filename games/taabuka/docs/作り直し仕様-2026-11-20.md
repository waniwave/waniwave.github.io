# ター深 作り直し仕様（2026-11-20 決定）

テストプレイの指摘から決めた、ルールの芯と見た目の作り直し。進行・宿・潜行・脱出の仕組みは残す。

## A. すぐ直すもの

- **読み込み中**：進み具合の帯（「札を並べています… 132/252」）、襖が流れる小さな動き、女将の一言（数秒ごとに入れ替え）。取り直し中は「回線が混んでいます。もう一度取りに行っています」
- **タイトル**：奥へ襖が開いて落ちていく動き、筆文字風の大きなロゴ、潜った回数と最深記録、BGM
- **試し場**：タイトルから消す。ロゴを10回叩くと出る（`?dev=1` は開発用に残す）
- **体力**：戦闘画面の手札の上に太いゲージ。減った分が白く残って遅れて縮む。被弾で画面の縁が赤く光る・揺れる・大きな「−12」。受けで防いだ分は別の色で「受け −8」。体力3割未満で縁が薄く赤く、心音。敵の予告「攻め 12」を大きく、食らった後の体力をゲージに点線で
- **蔵**：デッキの札は蔵の数に数えない。初期 40→60、改装後も同じ1.5倍で伸ばす
- **店**：札の削除をなくす

## B. 計算の芯

- 札に固有の数字はない。**1枚の強さ＝その札のカテゴリが上の表（Tier）のどこにいるか**。上の表の呼び名は Tier のまま
  - God 60 / 0 35 / 1 22 / 2 15 / 3 10 / 4 6 / 5 3 / 8 は出すたび 3〜60（仮）
  - カテゴリを複数持つ札は、一番高いTierを使う（足し合わせは札の効果に回す）
- **重なりの倍率**：出した札（最大5枚）の中で同じカテゴリが 1枚×1・2枚×1.5・3枚×2・4枚×2.5・5枚×3。カテゴリごとの倍率を全部掛け合わせる。複数カテゴリの札は各カテゴリに1枚ずつ数える
  - 1カテゴリのデッキは簡単に安定（最大×3）。2〜3カテゴリは引き次第で×7.5〜×15以上
- ポーカーの役は廃止。手番の形（手札8・出す2回・流す1回）は残す
- 最初は全カテゴリTier3（序盤は平坦）。Tierを動かす効果が中盤から効いてくる
- 敵の主張は新しい計算で自動対戦から取り直す
- 飽き（出したカテゴリが下がる仕組み）は入れない

## C. カテゴリの役割（MTGの色のように）

| カテゴリ | 役割 |
|---|---|
| 速さ | アグロ（先頭・1ターン目・出す回数） |
| 格ゲー | アグロ／コンボ（連続で出すほど伸びる・追撃） |
| 麺 | ステロイド（強さ・倍率の上乗せ、のびる） |
| 食べ物 | ステロイド／回復（満腹を溜めて一気に） |
| スレ | ドロー（引く・探す・手札上限） |
| ター | Tier操作（上げる・下げる・入れ替える・博打） |
| 宿 | コントロール（受け・予告を弱める・持ち越し） |
| 湯 | 回復／リセット（体力・Tierを戻す・状態を流す） |
| 校庭 | ロック（整列＝行動を遅らせる・縛りを外す） |
| 老 | 育つ／遅効（数ターン後・潜行の間ずっと） |
| 死 | 生贄（捨てる・体力を払う・瀕死ほど強い） |
| 動物 | 群れ（同カテゴリの枚数で伸びる） |
| ロボ | バニラ強化／組み換え（効果なしを強く・カテゴリを写す） |

- すべての札にシナジーの相手がいる（tools/check で「相手が少ない札」を数えて出す。少ない札は効果を強くする）
- カテゴリをまたぐシナジーを強く・多く。1カテゴリは揃えやすいが伸びは小さい。またぐデッキを助ける引く札を用意
- 効果なし（バニラ）は少しだけ残し、ロボの「効果なしを強くする」札で拾う
- シルバーバレット・コンボ・ロック・コントロールが成り立つように：敵の性質を潜る前・踊り場で見せる。守る系には「溜めて返す」勝ち筋を付ける。コンボを崩す敵も置く
- Tierを動かす敵（層主・精鋭の一部。得意カテゴリを下げる・全部入れ替える・全部Tier8にする など）
- 札の名前・カテゴリ・セットの分け方は今のまま。効果を作り直す（全656枚）

## D. レアリティ（1枚ごと。ハクスラの拾い物）

| レアリティ | 枠の色 | 数字の倍率 | 数字のない効果 | 刻印 |
|---|---|---|---|---|
| コモン | 灰 | ×1 | そのまま | 0 |
| アンコモン | 緑 | ×1.5 | そのまま | 0 |
| レア | 青 | ×2 | そのまま | 1 |
| レジェンダリー | 金 | ×3 | 2回発動 | 2 |
| ユニーク | 朱 | ×5 | 効果が広がる（続く・全部に効く） | 3 |
| ミシック | 虹 | ×8 | 広がる＋2回発動 | 3（うち1つはミシック専用の強い刻印） |

- 札の種類は「最低レアリティ」を持つ（今の段を読み替え：並→コモン、上→アンコモン、特→レア、極→レジェンダリー、神→ユニーク）
- 効果なしの札もレジェンダリーから2回採点、ユニーク3回、ミシック5回
- **刻印**：ランダムな小さいおまけ（カテゴリ＋1・先頭なら強さ＋・出すと1枚引く・体力＋ など）。同じレアリティでも当たり外れがあり厳選したくなる
- **合わせ**：同じ札・同じレアリティ3枚 → 1段上の1枚（仕込み場）。作れるのはレジェンダリーまで。**ユニークとミシックは拾うしかない**
- **出方**：深いほど高い。B1〜3 コモン・アンコモン中心 / B4〜 レア / B7〜 レジェンダリー / B10〜 ユニーク / B13〜 ミシックがまれに。精鋭・層主・寄り道の宝部屋は一段出やすい。帳場で買えるのはコモン〜アンコモン（改装でレアまで）
- **難しさ**：後半は高レアリティの札で押し切る前提。敵の主張は「その深さで拾える一段上のレアリティ」を前提に合わせる
- **脱出との兼ね合い**：ユニーク・ミシックは蔵で複製できない（レジェンダリーは費用が跳ね上がる）。保険の掛け金はレアリティで上がる。倒れた画面で失った札をレアリティの色付きで並べる

## E. 作る順番

1. A（すぐ直すもの）
2. 計算の芯（Tierの強さ・重なりの倍率）とレアリティ・刻印・合わせの仕組み、最初のデッキ
3. カテゴリごとの札の作り直し（セットごと）と、敵の性質・Tierを動かす敵
4. 自動対戦で主張の数字と出方を取り直す
5. 女将の案内と遊び方の文を新しいルールに合わせる
